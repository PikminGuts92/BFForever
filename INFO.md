# Song Project Structure
| File Name | Information |
| --------- | ----------- |
| notes.mid | RB3 formatted MIDI file |
| album.png | Album Art |
| video.bik | BIK encoded music video file |
| preview.ogg | Preview audio file |
| backing.ogg | Backing audio file (back) |
| bass.ogg | Bass audio file |
| drums.ogg | Drums audio file |
| rhythmguitar.ogg | Rhythm Guitar audio file (gtr1) |
| leadguitar.ogg | Lead Guitar audio file (gtr2) |
| vocals.ogg | Vocals audio file (vox) |
